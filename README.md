El proyecto consiste en el desarrollo de un sistema para almacenar Eventos universitarios. Se divide en 3 partes de codigo en las cuales se va aumentando la dificultad y los conceptos sopbre POO

Cada ejerciciio tiene su propia carpeta y un main para ejecutar, compilar y recorrer cada situacion

Ejercicio 1 - Encapsulamiento 
Se busca aplicar correctamente niveles de encapsulamiento, atributos finales, atributos de clase y un constructor de copia 

Ejercicio 2 - Relacion entre clases
Se escala el ejercicio 1 con la implmentacion de relaciones entre clases usan relacion de asosiacion, agregacion y composicion 

Ejercicio 3 - Herencia y polimorfismo
Se escala el ejercicio 2 usando los conceptos de herencia y polimorfismo con clases abstractas

¿Como ejecutar el proyecto?

Clonar el repositorio.
Abrir la carpeta del ejercicio deseado como proyecto en IntelliJ IDEA.
Ejecutar la clase Main.java .
La salida por consola muestra la creación de eventos, la asignación de salas, la creación de actividades, la inscripción de estudiantes y el resumen de datos de cada evento.
